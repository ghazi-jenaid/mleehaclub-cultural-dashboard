تعمل هذه الحزمة على Google Cloud Run، وتقرأ مجلد اللجنة في Google Drive
بصلاحية قراءة فقط. تتم المزامنة كل 60 ثانية إلى مرآة مؤقتة داخل الخادم، ثم
يستخدم التطبيق محرك المسح والمعاينة نفسه المستخدم في النسخة المحلية.

1. مشروع Google Cloud مرتبط بحساب فوترة.
2. تفعيل Cloud Run وCloud Build وArtifact Registry وGoogle Drive API.

4. مشاركة مجلد اللجنة مع بريد حساب الخدمة بصفة **Viewer** فقط.
